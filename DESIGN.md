# High-level design

This jj repo will contain the source code for a web application hosted under
kaputt.matze.lol with a purpose similar to uptime robot or [the unofficial
github status page](https://mrshu.github.io/github-statuses) but for pages
served by the city of Karlsruhe including (but check what others make sense):
karlsruhe.de, stadtbibliothek.karlsruhe.de, opac.karlsruhe.de,
geoportal.karlsruhe.de.

Tech stack:

- Rust backend
- sqlite database
- HTMX if necessary
- Simple, self-contained CSS
- Self-hosted Geist font
